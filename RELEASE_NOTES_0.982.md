# Release 0.982

Initial release of the `half-life-stanalone-quest-releases` repository.

- New VR renderer;
- Half-Life 2, Lost Coast, Episode One and Episode Two support;
- Windows and Linux cache builders, including automatic Lost Coast detection;
- complete redistributable VR compatibility overlay;
- one-time reset of launcher, game, graphics and VR settings to the new defaults after installation;
- saves, installed game resources and user mods are preserved by the settings migration.

The original commercial game data is not included. Build the cache from a legally installed Steam copy as described in the README.
