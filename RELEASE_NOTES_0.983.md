# Release 0.983

- Added spatial VRS1 peripheral shading;
- reduced redundant work for opaque windows, terrain and full world batches;
- improved command-thread scheduling around OpenXR frame submission;
- added VR crane controls;
- retained Half-Life 2, Lost Coast, Episode One and Episode Two support;
- retained the Windows and Linux cache builders and the complete redistributable VR compatibility overlay.

This update keeps the same Android package and signing certificate as 0.982. It does not add another settings reset. The one-time 0.982 migration remains available to users updating from older builds.

The original commercial game data is not included. Build the cache from a legally installed Steam copy as described in the README.
